Cloud Service Models

IaaS (Infrastructure as a Service)

Provides raw computing resources like virtual machines, storage, and networks over the internet.

Example: AWS EC2, Google Compute Engine

PaaS (Platform as a Service)

Offers a managed framework and environment for developers to build and deploy apps without managing servers.

Example: Heroku, AWS Elastic Beanstalk

SaaS (Software as a Service)

Delivers ready-to-use software applications completely over the web, typically via a subscription model.

Example: Google Workspace, Microsoft 365

Cloud Terminology Glossary

Auto-Scaling

Automatically adjusting compute resources based on real-time traffic demand.
